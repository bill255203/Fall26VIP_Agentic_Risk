# Contributors

This is the public contributor directory for the NYU Fall 2026 VIP. Each student's
linked portfolio records the work they contributed and the evidence for it.
Literature, pilot critique, reproduction attempts, reasoned proposals and rejections,
experiments, design, code, tests, data, analysis, documentation, review, and
presentations all belong in this record when linked to actual evidence.

## NYU Fall 2026 roster

Students join through their first pull request using the
[enrollment steps](docs/contributors/README.md#first-contribution).
Students add their own names and GitHub usernames; the instructor does not need
to collect them in advance. The roster is currently awaiting student enrollment.
Remove that last sentence when the first student joins.

## How credit is recorded

The portfolio links to the original issue, pull request, review, or artifact.
That evidence is the source of truth; the portfolio is a short index of outcomes.
The linked issue or pull request shows the current review and completion state.
Shared work names each person's actual contribution and can link to the same
evidence from multiple portfolios.

Use [the portfolio guide](docs/contributors/README.md) and
[template](docs/contributors/_template.md) to add or update a record. Credit
describes evidenced work and supports the cohort's authorship discussion; it
does not promise manuscript authorship. Commit counts and activity graphs are
not measures of contribution quality or a grading rubric.

The repository's founding scaffold and scripted pilot predate student enrollment.
Student portfolios should identify subsequent contributions accurately, including
reproduction or improvements to that starting point.

Start with [the student guide](docs/student-start.md) for reading, cloning, and
your first pull request. See [contribution workflow and Git attribution](CONTRIBUTING.md), the
[cohort guide](docs/cohort-guide.md), and the [repository overview](README.md).
