# Results

`results/local/` is for generated local runs and is ignored by Git.

A result snapshot may be committed outside `results/local/` only after review. It must include the generated manifest, exact configuration, trial-level traces or a documented access path, summary, interpretation, and limitations. Never commit sensitive or restricted data.

Deterministic scripted runs validate the harness. Label them as fixture or validation results rather than empirical findings about model behavior.
